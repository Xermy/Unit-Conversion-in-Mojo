# Unit Conversion in Mojo
A unit converter written in Mojo that allows for the conversion of temperature, length, liquid, speed and weight units.

## System requirements
* Mojo 1.0.0

## How to run
First clone the repository.
```bash
git clone https://github.com/Xermy/Unit-Conversion-in-Mojo.git
```
Clone into the project and activate the pixi environment.
```bash
cd 'Unit-Conversion-in-Mojo' && pixi shell
```
Then build the main file.
```bash
mojo build main.mojo
```
Then execute the binary.
```bash
./main
```
Or run the .mojo file.
```bash
mojo run main.mojo
```
